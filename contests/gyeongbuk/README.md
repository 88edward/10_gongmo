## 2. 경상북도

공개 공고 분야: 일자리·경제, 과학·산업, 에너지·환경, 보건·복지, 농축수산, 전통·문화·예술, 도정혁신 등 전 분야. 시·군이 따로 운영할 때 생기는 공백에 초점을 맞췄다.

| 번호·아이디어 | 불편·문제 가설 | 정책 운영 방식 | 차별점·성과 측정 |
|---|---|---|---|
| G1. 행정경계를 넘는 ‘가까운 농기계 공동예약’ | 가까운 임대사업소가 다른 시·군에 있거나 필요한 장비가 없어 멀리 이동할 수 있다. | 기종별 재고·예약 정보를 공유하고 이용 자격·요금·보험·운송 기준을 협약으로 조정한다. 인접 2~3개 시·군부터 시작한다. | 기존 장비 공동 이용. 이동거리, 예약 실패율, 가동률 측정. |
| G2. 농촌 진료예약과 귀가편을 함께 잡는 이동 지원 | 병원행 차편이 있어도 진료 종료시간과 귀가 교통이 맞지 않을 수 있다. | 의료기관과 예약시간을 묶고 기존 교통·이동지원 수단에 연계한다. 진료 지연 시 담당자가 귀가편 변경을 조정한다. | 진료 후 귀가까지 연결. 진료 취소율, 귀가 대기시간 측정. |
| G3. 빈집 ‘입주 준비도 확인서’ | 빈집 목록만으로 수리비, 임대 의사, 입주 가능 시점을 알기 어렵다. | 소유자 동의하에 누수·설비·안전·통신 상태와 예상 수리 항목, 임대 조건·입주 가능일을 표준 양식으로 공개한다. 전문 확인 필요 사항은 별도 표시한다. | 입주 가능성의 불확실성 해소. 계약 전환율, 입주 소요기간 측정. |
| G4. 소량 농산물 ‘공동 출하 최소물량 달성제’ | 소규모 농가는 운송비 부담이 크고 구매처 최소 발주량을 맞추기 어렵다. | 인접 농가의 같은 품목을 출하일별로 모아 최소물량 달성 시 공동 수거한다. 등급·포장·정산 기준을 사전 합의한다. | 출하 단위와 물류 운영 개선. 농가당 운송비, 출하 포기 물량 측정. |
| G5. 산불 대피 ‘차량 없는 주민 이동계획’ | 대피 안내를 받아도 차가 없거나 이동지원이 필요한 주민은 출발이 어려울 수 있다. | 희망 가구를 등록하고 탑승 장소·운전자·예비차량을 정한다. 재난 담당기관과 훈련하고 연락처·지원 필요 정보를 갱신한다. | 대피 실행 준비. 훈련 시 탑승 완료시간, 미연락 가구 비율 측정. |

우선 후보: **G1**. 도 단위 참여 이유가 분명하다. 핵심은 앱 개발보다 시·군 공동운영 협약이다.

## 작성 전제

- 대상: 안성시, 경상북도, 한국수력원자력, 서민금융진흥원, 용인시 공모전.
- 사용자가 처음 언급한 한국수자원공사와 달리 첨부 파일명은 한국수력원자력이므로, 첨부 파일명 기준으로 한수원 아이디어를 작성했다.
- 작업 환경 연결 오류로 첨부 HWP/HWPX 본문은 직접 읽지 못했다. 동일 공모전의 공개 공고를 참고한 1차 후보안이며, 첨부 신청서·심사 기준 전체를 검토한 최종안은 아니다.
- 아래 시민 불편은 검증할 문제 가설이며 실제 민원 조사 결과가 아니다.
- 이번 목록 안에서는 공모전별 핵심 기능이 겹치지 않게 구성했다. 이전 전체 아이디어, 기존 사업, 과거 수상작과의 중복 여부는 미확인이다.
- 우선 후보는 문제의 명확성과 실행 구조에 따른 판단이며 수상 가능성을 보장하지 않는다.
