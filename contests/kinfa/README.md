## 4. 서민금융진흥원

공개 모집 주제: 청년이 체감하는 정책 구현, 공공부문 AI 대전환, 국민 주도 참여·소통 거버넌스 구현.

| 번호·아이디어 | 불편·문제 가설 | 정책 운영 방식 | 차별점·성과 측정 |
|---|---|---|---|
| F1. 지원 부결 뒤 ‘다음 행동 안내서’ | 부결 후 보완할 수 있는지, 다른 지원을 찾아야 하는지 알기 어렵다. | 안내 가능한 사유를 쉬운 말로 설명하고 보완서류·재확인 조건·다른 상담 경로를 제공한다. 타 기관 연결은 동의 후 진행한다. | 부결 이후 공백 해소. 안내 이해도, 후속 상담 연결률 측정. |
| F2. 불규칙 소득 청년의 ‘생활비 공백 달력’ | 수입일과 월세·공과금 납부일이 어긋나 일시적인 자금 부족이 생길 수 있다. | 자발적 입력 또는 동의한 자료로 현금흐름을 시각화한다. 공백 예상 시 납부일 조정 가능 여부와 복지·상담 경로를 안내한다. | 돈이 부족해지는 시점에 집중. 예측오차, 사전 상담 이용률 측정. |
| F3. 설명을 반복하지 않는 상담요약서 | 기관을 옮길 때마다 소득·채무·취업 상황을 반복 설명해야 한다. | 이용자가 확인·수정한 요약서를 원하는 기관에 필요한 항목만 제공한다. 제공 범위·유효기간·철회 방법을 명확히 한다. | 상담 연속성 확보. 반복 설명시간, 추가 서류 요구 건수 측정. |
| F4. 금융 신청서 ‘어려운 표현 발견 AI’ | 어려운 문구가 입력 오류·신청 포기로 이어질 수 있다. | AI가 신청서·오류 문구의 어려운 표현과 대안을 제시하고 이용자가 이해도 실험에 참여한다. 담당자 검토 후 반영한다. | 신청 화면 자체 개선. 항목별 오류율, 신청 중단율 측정. |
| F5. 민원 답변 이후 ‘개선 결과 공개장부’ | 의견 제출 뒤 제도가 바뀌었는지 알기 어렵다. | 반복 불편을 익명화해 공개하고 이용자 패널이 우선순위에 참여한다. 채택·보류 사유, 담당부서, 개선 결과를 기록한다. | 실제 변화 과정 공개. 처리기간, 동일 민원 재발률 측정. |

우선 후보: **F1**. 기존 부결 안내·복합지원과 비교해 추가되는 단계를 구체화해야 한다.

## 작성 전제

- 대상: 안성시, 경상북도, 한국수력원자력, 서민금융진흥원, 용인시 공모전.
- 사용자가 처음 언급한 한국수자원공사와 달리 첨부 파일명은 한국수력원자력이므로, 첨부 파일명 기준으로 한수원 아이디어를 작성했다.
- 작업 환경 연결 오류로 첨부 HWP/HWPX 본문은 직접 읽지 못했다. 동일 공모전의 공개 공고를 참고한 1차 후보안이며, 첨부 신청서·심사 기준 전체를 검토한 최종안은 아니다.
- 아래 시민 불편은 검증할 문제 가설이며 실제 민원 조사 결과가 아니다.
- 이번 목록 안에서는 공모전별 핵심 기능이 겹치지 않게 구성했다. 이전 전체 아이디어, 기존 사업, 과거 수상작과의 중복 여부는 미확인이다.
- 우선 후보는 문제의 명확성과 실행 구조에 따른 판단이며 수상 가능성을 보장하지 않는다.
